FM ARCAVE on your FM-1

This page puts FM ARCAVE on an M-VAVE FM-1 over USB. It takes about two minutes. You need Chrome or Edge on a computer, and a USB cable that carries data.

FM ARCAVE replaces the firmware that is on the FM-1 now, and that firmware's songs and presets may not survive. It is a community firmware: installing it is at your own risk. It has not yet been run on an FM-1 by anyone but its build checks; see "Where this stands" below.

  1. CONNECT

    Plug the FM-1 into this computer, switch it on, and close any other program that uses it (a DAW, another installer). Then let this page use MIDI when the browser asks.

    Not connected

  2. INSTALL

    Leave the cable in and the FM-1 on until this page says it is done. The FM-1's screen shows FM ARCAVE and a bar while it writes.

  3. PLAY

    The FM-1 restarts into the title. Press PLAY. OCT- and OCT+ change the language, GLO opens the settings.

THE WAY BACK

Any other firmware installs over FM ARCAVE the usual way: the Firmware Hub, another firmware's installer, or M-VAVE's own updater with the official file.

If the FM-1 does not start, hold OCT- while switching it on. That is the USB rescue: no sound, only the updater, and this page (or any installer) can reach it. If an install was cut off, plug in again and press INSTALL: the FM-1 stays in update mode until one finishes.

WHERE THIS STANDS

The package on this page is built from the source by the project's own build, which refuses anything that would not fit or would touch the wrong part of the flash. It stands on Dinghy's platform, which other firmwares run on the FM-1 every day. The game itself has been played in the browser build and in tests on a computer. Timing, screen speed and sound level on the real device are the first things to check.
