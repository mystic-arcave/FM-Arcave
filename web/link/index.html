Each FM-1 keeps its own scene and its own tune. This page keeps their bars and beats together: it listens to every FM-1 that has LINK on, takes one as the leader, and tells the others where the leader's clock is.

HOW TO CONNECT

By USB: plug each FM-1 into this computer (a USB hub is fine). A browser tab running the emulator with MIDI on counts as an FM-1 too, through a virtual MIDI port. Bluetooth is not in this version of the firmware yet: the messages are made to pass over Bluetooth MIDI, but the FM-1's radio code is still to be brought over.

WHAT STAYS IN TIME

Tempo, beat and bar. A follower slides into place over a beat or two, never jumps mid-note. Change the tune on the leader (ALGORITHM) and every FM-1 takes its tempo. With LINK on, all of FM-ARCAVE's tunes play in one shared key, so different tunes on different machines still agree.

HOW CLOSE

The page measures each FM-1's delay with a ping and sends each one the clock moved ahead by that much. "OFF BY" shows how far each FM-1 is from the leader. These numbers come from the emulator so far, not from four FM-1s on a table.

UNDERSONG, FOR TWO OR THREE

The game for two or three FM-1s, down the well in the Arcave's floor. Plug them all into this computer, start the hub, and roll each Rock to the well: this page passes what each player does to the others, and the clock of the one that leads. With three in the well, every game is played for three. LINK does not have to be on for it. Friends on other computers: the ONLINE tab.

WITHOUT THIS PAGE

An FM-1 with LINK on also follows a plain MIDI clock (USB or the TRS jack) from a DAW or a drum machine, and START sets it to bar one.

The messages are control changes 102 to 118 on MIDI channel 16; docs/LINK.md has the whole protocol. Nothing leaves this computer.
